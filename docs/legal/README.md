# Юридические документы AnnWord

В проекте размещены финальные тексты юридических документов для ограниченного и публичного запуска. Исходники хранятся в архиве `legal-src/legal-documents.b64.part*`, а PDF автоматически формируются командой `python3 scripts/generate_legal_pdfs.py` во время сборки.

Публикуемые документы:

- пользовательское соглашение;
- публичная оферта AnnWord Premium;
- политика обработки персональных данных;
- политика cookie и локального хранилища;
- согласие на обработку персональных данных пользователя;
- согласие законного представителя на обработку данных ребёнка;
- согласие на рекламные и информационные сообщения.

Контакт для обращений, указанный в документах: `support@annword.ru`.
